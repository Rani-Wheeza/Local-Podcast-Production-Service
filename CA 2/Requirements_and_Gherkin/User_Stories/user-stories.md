# User stories

The user stories for Scenario 29 come from the CA1 analysis and are unchanged in CA2:
[`CA 1/Requirements/user-stories.md`](../../../CA%201/Requirements/user-stories.md) (US1–US12).

CA2 traces them through the revised analysis baseline (`Group_Documents/Analysis_Baseline/`) and the Gherkin feature files in `../Feature_Files/`, where each scenario is tagged with its requirement and use case.

Changes agreed in CA2 that affect the stories:

- **US1:** FR1 now also records who proposed a programme (DEC-07).
- **US2:** a decision can include a note, such as a reason for rejection (DEC-08).
